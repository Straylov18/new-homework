# Запуск кода на разных этапах жизни страницы (в данном примере при старте)

Во Vue, как и в других крупных фреймворках есть возможность запустить какой-то код в разные моменты жизни страницы.
В самом частом случае бывает нужно сделать какие-то запросы на бэк при старте приложения.
Также часто исполняют свой код при закрытии страницы приложения.

Подробнее о том, в какие моменты во Vue можно вызывать свои функции можно почитать тут:
https://vuejs.org/guide/essentials/lifecycle.html.

## Исполнение кода при загрузке страницы или элемента

Допустим у нас имеется приложения с несколькими страницами.
Добавим в каждую из них код, который будет выполняться при переходе на эту страницу при помощи метода **onMounted**:
```vue
<script setup lang="ts">
import { onMounted, ref } from 'vue'

const isLabel = ref<boolean>(false);

function showLabel() {
  isLabel.value = true
  setTimeout(() => {
    isLabel.value = false
  }, 5000)
}

onMounted(() => {
  showLabel()
})
</script>
```
Получается здесь при старте приложения вызовется метод showLabel.
В методе showLabel переменной isLabel задается значение true и ставится таймер на 5 секунд, 
по истечению которого isLabel станет false.

Чтобы можно было увидеть изменение переменных на каждой странице добавим текстовые теги, 
которые отображаются только если значение переменной isLabel равно true.
```vue
<v-label class="green-label" v-if="isLabel">Такая-то страница загрузилась</v-label>
<v-label class="green-label" v-if="isLabel">(сообщение уйдет через 3 секунды)</v-label>
```

Тогда мы увидим, что в **App.vue** метод onMounted отрабатывает только при начальной загрузке приложения, 
а на страницах каждый раз при переходе на них.
Таким образом можно описывать события для разных стадий жизненных циклов 
самого приложения, страниц (описываемых через роутер), компонентов.
