# Использование переменных окружения для задания настроек web приложения

Порой необходимо собрать веб приложения под несколько стендов.
Например, сделать отдельные версию для показа заказчику и для тестирования, 
Для упрощения сборки под разные случаи, в приложениях использую переменные, 
берущиеся из окружения системы или из специальных **.env** файлов.
В случае web приложений эти переменные подтягиваются сборщиком при сборке приложения.
В данном курсе в качестве сборщика выступает Vite.

## Использование переменных окружения в приложении и загрузка их из .env файлов

Добавим загрузку переменных окружения (в том числе из **.env** файла) при создании defineConfig в **vite.config.ts**:
```ts
import {defineConfig, loadEnv} from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig(({ mode }) => {
    const env = loadEnv(mode, process.cwd());
    return {
        plugins: [
            vue(),
            vuetify()
        ],
    }
})
```
Такая конфигурация Vite будет подгружать все переменные окружения, начинающиеся с **VITE_**!

При такой конфигурации переменные окружения для локальной сборки (при запуске "npm run dev") 
будут браться из **.env** файла.
Опишем переменную в  **.env** файле:
```
VITE_APP_GREETING_MESSAGE="Hello localhost!"
```
Еще раз обрати внимание, что Vite будет подгружать все переменные окружения, начинающиеся с **VITE_**!

При сборке же проекта для отправки на прод будет использоваться переменные из **.env.production** файла:
```
VITE_APP_GREETING_MESSAGE="Hello prod!"
```

Используем переменную окружения в **App.vue**:
```vue
<script setup lang="ts">
  import {ref} from "vue"
  const greetingMessage = ref<string>(import.meta.env.VITE_APP_GREETING_MESSAGE)
</script>

<template>
  <h1>{{ greetingMessage }}</h1>
</template>
```
Здесь переменная окружения VITE_APP_GREETING_MESSAGE импортируется в переменную greetingMessage в разделе **script**, 
а потом используется в разделе **template**.
