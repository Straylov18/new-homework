# Реактивное изменение компонентов при помощи функционала Vue

## Структура .vue файлов

Во Vue можно как использовать классические файлы для описания кода 
(например, **src/main.ts**, **src/style.css**, **index.html**), 
так и описывать компоненты и страницы полностью в одном **.vue** файле.
По умолчанию в **.vue** файле есть три секции:
- **template** под описание разметки
- **script** под описание бизнес логики (JS/TS)
- **style** под описание css классов

По умолчанию во Vue приложении есть главный файл **App.vue**, 
содержимое которого при сборке вставится в главный **index.html**.

## Получение данных из компонентов

Для начала на примере использования компонентов библиотеки vuetify 
(как ее подключать смотри в предыдущем уроке) 
сохраним состояние какого-то элемента в переменную.

Все компоненты библиотеки vuetify начинаются с приставки "v-" (например, "v-btn", "v-row", итд.).
Использование префиксов в названиях является частой практикой именования компонентов в библиотеках.

### Добавление кнопки на страницу

Добавим в template файла App.vue кнопку из библиотеки vuetify, 
обернутую в таблицу, контейнер и объявление vuetify приложения:
```vue
<template>
  <v-app>
    <v-container max-width="600">
      <v-row>
        <v-btn class="v-col-12">
          Отобразить остальные элементы
        </v-btn>
      </v-row>
    </v-container>
  </v-app>
</template>
```
Рассмотрим используемые компоненты из кода выше:
- v-app
В дальнейшем понадобиться для задания темы приложения.
```vue
<v-app>
</v-app>
```
Подробнее о свойствах этого компонента и примерах использования можно почитать тут:
https://vuetifyjs.com/en/api/v-app/

- v-container
```vue
<v-container max-width="600">
</v-container>
```
Он содержит в себе все наполнение страницы, таким образом все компоненты не могут выйти за его максимальную ширину.
Подробнее о свойствах этого компонента и примерах использования можно почитать тут:
https://vuetifyjs.com/en/api/v-container/, https://vuetifyjs.com/en/components/grids/.

- v-row
Компоненты v-row и v-col нужны для задания столбцов и колонок в табличной верстке.
```vue
<v-row>
</v-row>
```

Подробнее о свойствах этого компонента и примерах использования можно почитать тут:
https://vuetifyjs.com/en/api/v-row/, https://vuetifyjs.com/en/components/grids/.

- v-btn
Задание кнопки на которую модно будет поставить обработчики событий.
```vue
<v-btn class="v-col-12">
  Отобразить остальные элементы
</v-btn>
```
У этой кнопки будет название "Отобразить остальные элементы", 
при этом она будет растянута на всю строку, 
поскольку у нее указано количество занимаемых колонок (v-col-12 - специальный класс).

Подробнее о свойствах этого компонента и примерах использования можно почитать тут:
https://vuetifyjs.com/en/api/v-btn/.

Вообще в разработке frontend приложений очень часто используются 12-ти колоночная система верстки.
В такой системе весь родительский элемент занимает условные 12 колонок, 
и для задания дочерним элементам ширины можно просто указать количество занимаемых колонок.

Подробнее о реализации 12-ти колоночной системы верстки во vuetify и примерах использования можно почитать тут:
https://vuetifyjs.com/en/components/grids/.

### Добавление обработки нажатий на кнопку

Теперь можно привязать вызов какого-нибудь метода к нажатию кнопки.

Для этого опишем этот метод в разделе **script** в **App.vue** файле:
```vue
<script setup lang="ts">
import {ref} from "vue"

const isShowing = ref<boolean>(false)

function handleClick() {
  isShowing.value = !isShowing.value
}
</script>
```
В данном примере в разделе **script** пишется код на языке TS.
Чтобы Vue понимал, на чем написан код, укажем язык в параметрах раздела **script** (lang="ts").

Здесь задаются:
- boolean свойство isShowing, 
которое в дальнейшем будет использоваться при отображении компонентов данного урока
- функция handleClick, 
которая при вызове будет менять свойство isShowing на противоположное значение

В остальном это обычной код на TS.
Для большего понимания настоятельно рекомендуется посмотреть вводные уроки по TS.

Чтобы привязать метод handleClick к событию нажатия кнопки, 
можно в тэг v-btn добавить свойство @click="handleClick".
Также для проверки, отобразим свойство isShowing над кнопкой.
Тогда раздел **template** будет выглядеть следующим образом:
```vue
<template>
  <v-app>
    <v-container max-width="600">
      <v-row>
        {{ isShowing }}
        <v-btn class="v-col-12" @click="handleClick">
          Отобразить остальные элементы
        </v-btn>
      </v-row>
    </v-container>
  </v-app>
</template>
```

Свойства, начинающиеся с "@" отвечают за обработку событий.
Подробнее об обработке событий на Vue можно почитать тут:
https://vuejs.org/guide/essentials/event-handling.html

Теперь при нажатии на кнопку isShowing будет меняться с false на true и обратно.

## Использование данных из раздела script для изменения состояния приложения

Во Vue можно делать JS/TS вставки кода в html разметку.
При этом если данные изменяются, все места с вставками кода тоже сами обновляются!
Автоматическое обновление системы в зависимости от изменения потока данных называется **реактивностью**.
Подробнее о реактивности на Vue можно почитать тут: 
https://vuejs.org/guide/essentials/reactivity-fundamentals.html.

Зададим несколько свойств, которые будут высчитываться на основе данных из **script** раздела. 

### Свойство v-if

Добавим еще одну строку ниже, которая будет отображаться только если isShoving равно true:
```vue
<v-row v-if="isShowing">
  <v-textarea></v-textarea>
</v-row>
```
Здесь параметр v-if="isShowing" говорит, что элемент будет скрываться, 
когда выражение в кавычках равно true (в данном случае переменная isShowing).
Элемент "v-textarea" представляет собой поле для многострочного ввода текста.

Подробнее об отрисовке по условию на Vue можно почитать тут:
https://vuejs.org/guide/essentials/conditional.html.

У компонентов ввода зачастую есть специальное свойство "v-model", 
через которое можно связывать введенное значение с указанной переменной.
Привяжем введенный в v-textarea текст с новой переменной inputText.
В разделе **script** тогда необходимо добавить:
```vue
const inputText = ref<string>("")
```
а задание элемента тогда будет выглядеть следующим образом:
```vue
<v-textarea v-model="inputText"></v-textarea>
```

Подробнее о двусторонней привязке переменных к данным элемента на Vue можно почитать тут:
https://vuejs.org/guide/components/v-model.html.

### Свойство v-for

Добавим под имеющимися двумя строками еще одну строку, 
на которая будет содержать каждую букву введенного выше текста в виде кнопки:
```vue
<v-row v-if="isShowing && true">
  <v-btn v-for="char in inputText" :key="char">
    {{ char }}
  </v-btn>
</v-row>
```
Здесь кнопка дублируется столько раз, 
сколько символов в строке inputText благодаря циклу типа for each 
(свойство v-for="char in inputText").
Внутри же кнопки символ отображается при помощи конвертации JS/TS вставки в язык верстки 
(имеется ввиду конструкция "{{ код }}"), где вызывается итерируемая переменная char.

Подробнее об отрисовке списков на Vue можно почитать тут:
https://vuejs.org/guide/essentials/list.html.

### Вычисляемые свойства (начинающиеся с ":")

Теперь сделаем так, 
чтобы цвет символа в кнопке менялся в зависимости от ее порядка в тексте.

Для начала немного изменим цикл, описывающий дублирование компонента v-btn така, 
чтобы v-btn имел информацию о своем порядковом номере.
Описание цикла в кнопках с символами будет выглядеть следующим образом: 
```vue
<v-btn v-for="(char, index) in inputText">...</v-btn>
```

С помощью переменных во Vue можно изменять также и стандартные свойства, 
которые этого не предусматривают по умолчанию.
Для этого необходимо перед описанием свойства написать ":", 
тогда можно будет описать его при помощи JS/TS кода.

Опишем таким способом стандартное свойство style, 
позволяющее задавать отдельные css параметры для элемента.
Чтобы это свойство можно было применить только на текст кнопки, 
обернем текст во vuetify компонент v-label:
```vue
<v-btn v-for="(char, index) in inputText">
  <v-label :style="`color: rgb(${index*10}, 0, ${index*2})`">
    {{ char }}
  </v-label>
</v-btn>
```

Таким образом Vue позволяет очень просто интегрировать логику JS/TS кода в верстку приложения.
