# Путь становления DevOps инженера

В данном документе предлагается последовательность изучения технологий 
для начинающего DevOps инженера.

## Основы разработки приложений

Понимание работы системы контроля версий git (github / gitlab / bitbucket).
Выбор основного языка написание небольших программ для автоматизации, например python (или Go).

Понимание как вообще команда работает над одним проектом, как доставляет изменения итд.

### Основы Python

[Курс python для начинающих](https://github.com/TheYeniseiTrireme/homework-materials/blob/main/python-basics-lessons/README.md).

## Базовое понимание системного администрирования

Умение комфортно работать в unix-подобных системах.

Умение полностью жить в терминале, знание bash (желательно уметь выходить из vim:))

Понимание как работает операционная система, причем чем глубже тем лучше, 
но для начала понимать как в Linux работают:
- права доступа
- пользователи
- процессы (создание новых и форки)
- файловая система
- сети
- фоновые и регулярные задачи
- пространства имен (namespaces)

Понимание как работают сетевые протоколы разного уровня.
Понимание как происходит симметричное / асимметричное шифрование в разных протоколах.

Поработать со старым добрым ssh.

### Настройка веб серверов

Как базу стоит взять nginx, 
плюс иметь хоть какое-то представление о работе других веб серверов вроде того же Tomcat.

Понимание как работают:
- прокси
- обратные прокси
- балансировщики
- межсетевые экраны
- кэширующие прослойки

Понимание как работает https, SSL/TLS, DNS.
