# Ограничение числа запросов на основе библиотеки slowapi

Зачастую при написании middleware можно использовать уже существующие библиотеки.

Так, для ограничения количества запросов пользователей 
можно использовать популярную библиотеку slowapi.
Она позволяет выставлять различные ограничения по запросам для конкретных ручек.

## Конфигурация через limiter

Для начала необходимо задать ограничители запросов 
(для разных стратегий ограничения и разных способов хранения информации об этих ограничениях).
В нашем случае это будет один ограничитель 
для ограничений количества запросов в рамках фиксированного периода:
```python
from slowapi import Limiter
from slowapi.util import get_remote_address

from src.config import settings

limiter = Limiter(
    key_func=get_remote_address,  # функция проверяет уникальность клиента по адресу (можно пропихивать сюда свою)
    strategy="fixed-window",  # фиксированные периоды (а можно например сделать так, чтобы время между запросами каждый раз увеличивалось)
    storage_uri="memory://",  # храним информацию о последних запросах в памяти
    enabled=settings.RATE_LIMITING_ENABLED,
)
```
Здесь:
- параметр ```key_func=get_remote_address``` указывает функцию проверяющая уникальность клиента по адресу 
(можно пропихивать сюда свою)
- параметр ```strategy="fixed-window"``` задает стратегию ограничения запросов с фиксированным периодом 
(те мы будем дальше указывать сколько запросов пользователь может делать в один период времени)
- параметр ```storage_uri="memory://"``` указывает, 
что информацию о последних запросах пользователй в оперативной памяти нашего бэкенд приложения 
(можно вместо этого выбирать всяческие базы данных)
- параметр ```enabled=settings.RATE_LIMITING_ENABLED``` - подтягивает из конфига настройку, 
которой можно будет отключить ограничитель запросов

Порой принято делать другие стратегии ограничения запросов
(например такие, при которых время блокировки ручки для пользователя все время увеличивается).
Больше информации о стратегиях ограничения запросов можно почитать тут:
https://limits.readthedocs.io/en/stable/strategies.html.

Также мы выбрали хранить информацию о запросах пользователей в оперативной памяти приложения.
Если приложение будет перезапускать они потеряются.
Также если используется несколько узлов бэкенд приложения,
которые одновременно делят между собой нагрузку порой необходимо,
чтобы эта информация была одна на все узлы бэкенда приложения
(что часто делают через внешние средства, но можно и с помощью этой библиотеки внутри бэкенда).

Для этого очень часто принято хранить информацию о запросах пользователя в какой-либо базе данных
(например, redis).
Подробнее об это можно почитать тут:
https://limits.readthedocs.io/en/stable/storage.html.

## Применения ограничителей на ручках

Напишем в **src/route/some_routes.py** теперь ручку, 
которую можно будет вызывать только 5 раз в минуту:
```python
from time import sleep

from fastapi import Request
from fastapi.routing import APIRouter

from src.config import settings
from src.rate_limiter import limiter

router = APIRouter(prefix=settings.BASE_ROUTE_PATH)


@router.get('/some-complex-logic')
@limiter.limit("5/minute", per_method=True)
async def sleepy_get(request: Request):  # параметр 'request: Request' должен быть при использовании limiter декоратора
    sleep(1)
    return 'Done!'
```
Здесь:
- декоратор ```@limiter.limit("5/minute")``` говорит, 
что эта ручка может вызываться пользователем не чаще, чем 5 раз в минуту
- параметр ```per_method=True``` указывает, 
что ограничение будет применяться к конкретному http запросу.
- параметр функции ```request: Request``` 
является обязательным при использовании данного декоратора

Описание периодов доступности также можно комбинировать.
Например, напишем в **src/route/some_routes.py** другую ручку, 
которая будет доступна не более 1 раза в секунду и не более 5 раз в минуту: 
```python
@router.get('/hello')
@limiter.limit("1/second", per_method=True)
@limiter.limit("5/minute", per_method=True)
async def hello_world(request: Request):  # параметр 'request: Request' должен быть при использовании limiter декоратора
    return 'Hi mam!'
```
