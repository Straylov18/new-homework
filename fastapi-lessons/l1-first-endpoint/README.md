# Настройка простого backend приложения на fastapi и обработка REST запросов

## Создание python проекта

Для начала создадим простой python проект, 
который будет состоять из одного пакета **src**.
Внутри пакета **src** будут лежать пустой **__init__.py** и **main.py** с логикой работы приложения.

Поскольку наш проект будет использовать сторонние зависимости 
(как минимум тот же fastapi),
мы должны для начала подгрузить их в проект. 
Подгружать зависимости будем с помощью библиотеки poetry ().

Файл с зависимостями **pyproject.toml** (и прочими настройками проекта) 
мы можем создать с помощью того же poetry.
Для этого в корневой директории проекта (в данном примере корневая папка это **l1-first-endpoint**) выполним команду:
```shell
poetry init
```
Данная команда в интерактивном режиме поможет заполнить базовые настройки проекта.
Также данная команда создать директорию окружения проекта **.venv**, в которую и устанавливаются все зависимости.

Если нужно добавить зависимости уже после создания проекта, это можно сделать с помощью команды:
```shell
poetry add fastapi uvicorn
```
В данном случае мы добавили в зависимости пакеты:
- fastapi (backend фреймворк)
- uvicorn (нужен для запуска backend приложения на python в асинхронном режиме, о нем чуть позже)

Если же нужно создать окружение для проекта с существующим **pyproject.toml**, то можно выполнить:
```shell
poetry lock
poetry install
```

## Простое приложение на fastapi

Для инициализации fastapi добавим в main:
```python
from fastapi import FastAPI

app = FastAPI()
```

Для удобного описания REST эндпоинтов (ручек) создадим APIRouter. 
Чтобы у всех наших ручек был общий префикс добавим его при создании роутера.
```python
from fastapi.routing import APIRouter

BASE_ROUTE_PATH = "/api/v1"
router = APIRouter(prefix=BASE_ROUTE_PATH)
```

Создадим простую ручку, при запросе на которую приложение будет возвращать текст:
```python
@router.get('/hello-world')
async def hello_world():
    return "Hi mam!"
```

Далее необходимо сделать так, чтобы fastapi видел наш роутер:
```python
app.include_router(router)
```

Для описания поведения приложения при запуске **main.py** файла, 
в конце файла запустим uvicorn, если запуск производился через **python main.py**:
```python
import uvicorn

if __name__ == '__main__':
    uvicorn.run(
        'main:app',
        host='localhost',
        port=8000,
        reload=True,
    )
```
При запуске uvicorn таким способом в параметрах зададим ему 
главный файл проекта, 
адрес (на котором работает приложение) с его портом, 
и настройку отвечающую за перезапуск приложения если его код был изменен 
(для более удобной разработки).

Чтобы запустить проект, можно подтянуть созданное окружение и запустить файл **main.py**:
```shell
source .venv/bin/activate
python src/main.py
```

Когда проект запустился, ты можешь попробовать дернуть созданную ручку с помощью команды **curl** из консоли 
(можешь и с помощью приложений вроде **postman**, **restclient**, итд.).
Адрес, на который нам надо будет отправить запрос будет состоять из:
- адреса, на котором развернулось приложение (поскольку мы делаем это локально, то это 'http://localhost')
- порта, на котором работает приложение (мы указывали '8000')
- префикса роутера (мы указывали '/api/v1')
- названия ручки (в данном случае 'hello-world')

Тогда вызов по итоговому адресу будет выглядеть:
```shell
curl http://localhost:8000/api/v1/hello-world
```

Приложение должно вернуть нам текст "Hi mam!".
