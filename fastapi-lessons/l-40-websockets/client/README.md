# Pygame WebSocket Client

Простейший 2D-клиент на **pygame**: игроки отображаются в виде цветных
квадратов и ходят по экрану. 
Вся координация происходит через **WebSocket**
с сервером из соседней папки [`server`](../server/).

## Конфигурация (.env)

Все настройки подключения и игры лежат в [`.env`](.env) и подтягиваются
в [`src/config.py`](src/config.py) через `pydantic-settings`. 

`SERVER_URL` — адрес WebSocket-сервера; при необходимости поменяйте его,
например, чтобы подключаться к серверу по сети.

## Запуск

1. Сначала запустите сервер (см. [`server/README.md`](../server/README.md)).
2. Затем запустите клиент при помощи команды `make`

Можно запустить несколько клиентов одновременно — они будут видеть друг друга.

## Управление

- **Стрелки** или **WASD** — движение квадрата-игрока.

## Как устроен клиент

- [`src/config.py`](src/config.py) — настройки из `.env` (`pydantic-settings`).
- [`src/main.py`](src/main.py) — точка входа, главный цикл pygame.
- Поток `WebSocketClient` читает сообщения сервера в фоне и кладёт их в очередь.
- Главный цикл pygame:
  1. разбирает входящие сообщения (появление/уход/перемещение игроков);
  2. обрабатывает нажатия клавиш и двигает локального игрока;
  3. отправляет `{"type": "move", "x": ..., "y": ...}` на сервер;
  4. рисует всех игроков квадратами на экране.

## Зависимости

- `pygame` — графика и обработка ввода.
- `websocket-client` — клиент WebSocket (читается в отдельном потоке).
- `pydantic-settings` — чтение настроек из `.env`.
