# Генераторы

Порой при работе с последовательностями не держать ее всю в памяти, 
а получать по определенному алгоритму постепенно. 
Для этого в python есть генераторы, 
которые будут выдавать обрабатывать следующее значение и выдавать его
только когда его попросят.

## Простой генератор

Генератор по сути является специальной функцией, 
выполнение которой можно останавливать на определенных этапах при помощи ```yield```.
В момент остановки генератор выдает какое-то значение 
(которое написано после ```yield```). 

При помощи специальной функции ```next(your_generator)``` 
в питоне можно продолжить выполнение функции 
до момента выдачи следующего значения.

Создадим простой генератор, 
который будет последовательно выдавать нам 3 значения:
```python
def some_generator():
    yield "1 значение"
    yield "2 значение"
    yield "3 значение"
```
Этот генератор будет по очереди выдавать 3 значения 
("1 значение", "2 значение", "3 значение").

При вызове этой функции будет создаваться генератор:
```python
gen1 = some_generator()
```
Чтобы получить от него следующее значение, 
необходимо передать в функцию next созданный генератор:
```python
print(next(gen1))  # выдаст "1 значение"
print(next(gen1))  # выдаст "2 значение"
print(next(gen1))  # выдаст "3 значение"
# print(next(gen))  # выдаст ошибку если нечего больше выдавать (те если дойдет до StopIteration)
print(next(gen1, None))  # чтобы при окончании последовательности не появлялась ошибка, можно ставить значение по умолчанию у next
```

Поскольку все циклы for на самом деле работают с последовательностями, 
у которых должен быть метод next, мы можем использовать в циклах и генераторы.

Перепишем получение данных от нашего генератора через цикл for:
```python
gen2 = some_generator()
for i in gen2:  # for цикл под капотом как раз использует next метод до тех пор, пока не наткнется на StopIteration
    print(i)  # выдаст "1 значение", потом "2 значение", потом "3 значение"
```

Многие стандартные функции, которыми мы часто пользуемся, являются генераторами (тот же range).

## Пример хранения состояния в генераторах

Поскольку генератор является функцией, мы можем передавать ему параметры при создании.
Напишем генератор чисел Фибоначчи 
(каждое следующее равно сумме двух предыдущих, начиная с двух единиц). 
Пусть он будет выдавать столько чисел, 
сколько его спрашивают при создании 
(те. принимать число чисел, которое должен сгенерить в параметрах).

Допустим этот генератор будет выглядеть так:
```python
def fibonacci_numbers(n: int):
    last = 1
    before_last = 0
    for _ in range(n):
        yield last
        new_last = last + before_last
        before_last = last
        last = new_last
        # or just
        # yield last
        # last, before_last = last + before_last, last
```
В данном генераторе все переменные локального скоупа функции 
будут продолжать храниться между вызовами следующих значений,
и генератор сможет помнить какие числа были до этого.

Получить последовательность от генератора мы сможем все так же:
```python
for fn in fibonacci_numbers(5):
    print(fn)  # выдаст 1 1 2 3 5
```

## Однострочные генераторы

Мы уже затрагивали однострочные генераторы во втором уроке.
На самом деле под капотом они работают точно также.

Напишем простой однострочный генератор пяти чисел, 
которые будут равны их порядку в последовательности, умноженному на 2:
```python
short_form_generators = (i * 2 for i in range(5))
for i in short_form_generators:
    print(i)
```
Как можно заметить **range** - тоже генератор. 
Получается у нас здесь генератор вызывает под капотом еще один генератор.

## Конвейеры генераторов

Если генератор вызывает еще один генератор, 
то они оба будут выдавать следующие значения только тогда, 
когда это необходимо.

Получается мы можем делать конвейер из своих генераторов, 
где один будет вложен в другой.
Такие конструкции не будут занимать много дополнительного места при большой длине последовательности, 
потому что все будет выдаваться постепенно.

Напишем конвейер генераторов, 
который будет выдавать удвоенное значение индекса, 
где индекс сдвинут на 1:
```python
# следующий код выполниться без сохранения промежуточных листов
range_gen = range(5)
minus_one_gen = (i - 1 for i in range_gen)
multiply_by_2_gen = (2 * i for i in minus_one_gen)
for i in multiply_by_2_gen:
    print(i)
# выдаст -2, 0, 2, 4, 6 (иными словами числа соответствующие формуле 2*(i-1))
```

## Конвертации генераторов

При необходимости генераторы можно материализовать в лист (кортеж итд.):
```python
l = list(range(5))
print(l)  # выдаст [0, 1, 2, 3, 4]
```

Также мы можем получить число элементов генерируемой последовательности, 
без перевода в лист:
```python
length = sum(1 for _ in range(5))
print(length)  # выдаст 5
```
