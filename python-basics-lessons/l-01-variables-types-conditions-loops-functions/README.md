# База написания консольных приложений python

## Твое первое приложение

Python приложения принято писать в **.py** файлах.
Создадим **hello.py** файл и запишем в него следующий код:
```python
print('Hello world!')
```

Чтобы запустить его, 
необходимо установить интерпретатор python на твой компьютер, 
который выполнит этот код (можно с официального сайта python, можно из VSCode, итд.).

Когда ты установишь python на свой компьютер, 
ты сможешь запустить написанную выше программу из консоли при помощи команды:
```shell
python hello.py
```
При успешном запуске она выведет "Hello world!".

## Переменные и типы данных

В Python переменные создаются автоматически при присвоении им значения. 
В отличие от многих других языков программирования, 
в Python не нужно заранее объявлять тип переменной - 
интерпретатор сам определит его на основе присвоенного значения. 
Это называется динамической типизацией.

Базовый синтаксис создания переменных в Python "**имя_переменной = ее_значение**", например: 
```python
a = 1
```

Чтобы изменить значение существующей переменной, можно присвоить ей повторно новое значение.

### Задание переменных через ввод с консоли (input)

При написании консольных приложений можно считывать ввод пользователя через **input**.
```python
a = input()
print("Пользователь ввел: ", a)
```

### Примитивные типы данных (примитивы)

В питоне 3 примитивных типа данных: 
- строки
- числа
- логические переменные (boolean переменные, принимающие значения True или False)

При объявлении переменной python автоматически задает ей подходящий тип данных.

Например, при объявлении:
```python
a = 'string'
b = 1
c = 1.2
d = True
```
python автоматически задаст переменной "a" строковый тип, 
переменным "b", "c" - числовой тип, 
переменной "c" - логический тип.

### Базовые операции

Числовые данные можно видоизменять при помощи математических операторов:
- \+ (сложение) — складывает два числа
- \- (вычитание) — вычитает одно число из другого
- \* (умножение) — умножает два числа
- / (деление) — делит одно число на другое
- % (остаток от деления) — возвращает остаток от деления
- ** (возведение в степень) — возводит число в степень
- // (целочисленное деление) — делит одно число на другое и возвращает целую часть результата

Например, напишем код, складывающий два числа и выдающий результат сложения:
```python
a = 1
b = 2.2
c = a + b
print(c)
```
Этот код выведет 3.2.

Строковые данные можно присоединять друг к другу оператором сложения:
```python
a = 'ассаляму ' + 'алейкум'
print(a)
```
Код вернет 'ассаляму алейкум'.

Над логическими переменными можно производить логические операции с помощью следующих операторов:
- and — возвращает True, если оба операнда истинны, иначе — False
- or — возвращает True, если хотя бы один из операндов истинен, иначе — False
- not — инвертирует логическое значение операнда: возвращает True, если операнд ложный, и False, если операнд истинный

Например, следующий код вернет значение True:
```python
b = True and False
b = not b
print(b)
```

## Изменение типов данных

Чтобы перевести переменную из одного типа данных в другой, данные можно обернуть в специальную конструкцию:
- int() — преобразует значение к целому числу
- float() — преобразует значение к числу с плавающей точкой
- str() — преобразует значение к строке
- bool() — преобразует значение к логическому типу (True, False)

Например:
```python
a = int("42")
b = a + 27
print(b)
```
Данный код вернет число 69 (строка 42 преобразится в число, а потом сложится с 27).

## Условия (if else)

Условия задаются c помощью конструкции "if абстрактное_логическое_выражение:".
Чтобы выполнить код, при соблюдении этого условия (абстрактное_логическое_выражение), 
необходимо написать его ниже if выражения так, 
чтобы код имел дополнительный отступ относительно строки с if 
(отступ нужно сделать с помощью ровно одного нажатия клавиши "tab").
Код под if выполнится, если условие (абстрактное_логическое_выражение) примет значение True.

Напишем код, который будет выводить сообщение, 
если пользователь ввел "привет":
```python
input(a)
if a == 'привет':
    print('и тебе привет')
```
Здесь в логическом выражении (a == 'привет') используется оператор сравнивания '==',
который сделает это логическое выражение True, 
если переменные слева и справа равны. 
Если они не равны, логическое выражение примет значение False.

Когда строки с дополнительной табуляцией закончатся, 
описание if выражения тоже закончится.

Так следующий код:
```python
a = 1
if a == 1:
    print('a равно 1')

print('продолжается выполнение программы')

if a == 2:
    print('a равно 2')
```
выведет:
```
a равно 1
продолжается выполнение программы
```

Чтобы выполнить код при невыполнении логического условия, 
можно сразу после описания кода if выражения написать "else:".
Например:
```python
input(a)
if a == 'привет':
    print('и тебе привет')
else:
    print('пока!')
```
Тогда если пользователь введет 'привет', 
приложение выведет 'и тебе привет'. 
Если пользователь введет любой другой текст, программа выведет 'пока!'.

Как говорилось выше отступы должны быть именно относительно текущего if выражения, 
потому что оно само уже может быть с отступом. 
Например, если в приложении есть код, 
который должен запуститься при выполнении двух условий одновременно:
```python
input(a)
if int(a) > 5:
    if int(a) < 2:
        print('a больше 5 и меньше 2')
    else:
        print('a не больше двух')
else:
    print('a не больше 5')
```
Здесь использовались операторы сравнивания '>' (больше) и '<' (меньше).

Также в питоне используются логические операторы 
'!=' (не равно), '<=' (меньше либо равно), '>=' (больше либо равно).

## Функции (def)

Чтобы переиспользовать код в нескольких местах и сделать его более читаемым 
в python часто использую функции.
В простейшем виде функция выглядит следующим образом:
```python
def имя_функции(): 
    код, который хотим переиспользовать, называющийся телом функции
```

Исполнить код, написанный в функции, можно, написав имя_функции().
Например:
```python
def имя_функции():
    код, который хотим переиспользовать

имя_функции()
```

Если мы хотим сделать так, чтобы функция возвращала значение, можем описать результат через **return результат**.
Например, вот функция все время возвращающая 42:
```python
def get_number():
    return 42
```

Также функция может принимать на вход параметры, 
для этого их необходимо обозначить в скобках, 
тогда с ними можно будет работать как с отдельными переменными внутри функции.
Напишем функцию, получающую число на вход и возвращающую число на 1 большее:
```python
def get_incremented_number(input_number):
    return input_number + 1
```

Стоит понимать, что аргументы функции и объявленные внутри нее переменные не будут доступны снаружи функции.
При этом мы можем использовать переменные извне функции внутри нее, если они были объявлены ранее.

## Циклы (for, while)

Для автоматизации повторяющихся задач используются циклы.
Они позволяют выполнять определённый блок кода определенное количество раз,
без необходимости переписывать его несколько раз.

### while циклы

Очень часто в программировании встречаются задачи,
когда необходимо исполнять один и тот же кусок кода из раза в раз, до тех пор,
пока выполняется какое-либо условие.
Для подобных задач хорошо подходит цикл **while**:
```python
while условие:
    выполняющийся в цикле код
```

Вот несколько примеров его использования:
```python
i = 0
# цикл будет выполняться пока i не станет равной 5
while i < 5:
    i += 1

# цикл будет выполняться вечно, или пока его не остановят
while True:
    print("цикл выполняется")
```

### for циклы

Циклы **for** в Python удобно использовать 
для перебора элементов в коллекциях данных 
и для исполнения кода определенного количества раз.

Синтаксис:
```python
for текущее_значение_из_последовательности in последовательность_элементов:
    выполняющийся в цикле код
```

Например, чтобы сделать операции с каждым элементом последовательности:
```python
some_list = [1, 2, 3, 4, 5, 6]
for element in some_list:
    # переменная element будет принимать значения от 1 до 6, пробегаясь по элементам массива some_list
    print(element)
```

Причем в ходе выполнения цикла можно оперировать как со значением элемента, 
так его индекс в последовательности:
```python
some_list = ['q', 'w', 'e']
for (index, element) in enumerate(some_list):
    # в пепременной index будут храниться индексы элементов
    print(index, element)
```

### Функция range

Чтобы сгенерировать числовую последовательность и пробежаться по ней, 
часто используют стандартную функцию **range**:
```python
# пройтись по числам от 0 (включая) до 5 (не включая)
for i in range(5):
    print(i)

# пройтись по числам от 2 (включая) до 5 (не включая)
for i in range(2, 5):
    print(i)

# пройтись по числам от 2 (включая) до 5 (не включая) c шагом 2
for i in range(2, 5, 2):
    print(i)
```

### Преждевременная приостановка цикла (break)

Если необходимо преждевременно завершить цикл,
можно вызвать внутри него команду **break**.

```python
i = 0
# цикл будет выполняться пока его не остановит команда break
while True:
    i += 1
    print('i =', i)
    if i == 5:
        break
```

### Принудительный переход на следующий виток цикла (continue)

Чтобы заставить программу перескочить на следующую итерацию цикла,
можно использовать команду continue:
```python
for i in range(5):
    if i == 2:
        # сделать так, чтобы при проходе 2 она не печаталась
        continue
    print(i)
```
