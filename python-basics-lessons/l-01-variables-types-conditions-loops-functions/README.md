# База написания консольных приложений python

## Твое первое приложение

Python приложения принято писать в **.py** файлах.
Создадим **hello.py** файл и запишем в него следующий код:
```python
print('Hello world!')
```

Чтобы запустить его, 
необходимо установить интерпретатор python на твой компьютер, 
который выполнит этот код (можно с официального сайта python, можно из VSCode, итд.).

Когда ты установишь python на свой компьютер, 
ты сможешь запустить написанную выше программу из консоли при помощи команды:
```shell
python hello.py
```
При успешном запуске она выведет "Hello world!".

### Примитивные типы данных (примитивы)

В питоне 3 примитивных типа данных: 
- строки
- числа
- логические переменные (boolean переменные, принимающие значения True или False)

При объявлении переменной python автоматически задает ей подходящий тип данных.

Например, при объявлении:
```python
a = 'string'
b = 1
c = 1.2
d = True
```
python автоматически задаст переменной "a" строковый тип, 
переменным "b", "c" - числовой тип, 
переменной "c" - логический тип.

## Условия (if else)

Условия задаются c помощью конструкции "if абстрактное_логическое_выражение:".
Чтобы выполнить код, при соблюдении этого условия (абстрактное_логическое_выражение), 
необходимо написать его ниже if выражения так, 
чтобы код имел дополнительный отступ относительно строки с if 
(отступ нужно сделать с помощью ровно одного нажатия клавиши "tab").
Код под if выполнится, если условие (абстрактное_логическое_выражение) примет значение True.

Напишем код, который будет выводить сообщение, 
если пользователь ввел "привет":
```python
input(a)
if a == 'привет':
    print('и тебе привет')
```
Здесь в логическом выражении (a == 'привет') используется оператор сравнивания '==',
который сделает это логическое выражение True, 
если переменные слева и справа равны. 
Если они не равны, логическое выражение примет значение False.

Когда строки с дополнительной табуляцией закончатся, 
описание if выражения тоже закончится.

Так следующий код:
```python
a = 1
if a == 1:
    print('a равно 1')

print('продолжается выполнение программы')

if a == 2:
    print('a равно 2')
```
выведет:
```
a равно 1
продолжается выполнение программы
```

Чтобы выполнить код при невыполнении логического условия, 
можно сразу после описания кода if выражения написать "else:".
Например:
```python
input(a)
if a == 'привет':
    print('и тебе привет')
else:
    print('пока!')
```
Тогда если пользователь введет 'привет', 
приложение выведет 'и тебе привет'. 
Если пользователь введет любой другой текст, программа выведет 'пока!'.

Как говорилось выше отступы должны быть именно относительно текущего if выражения, 
потому что оно само уже может быть с отступом. 
Например, если в приложении есть код, 
который должен запуститься при выполнении двух условий одновременно:
```python
input(a)
if int(a) > 5:
    if int(a) < 2:
        print('a больше 5 и меньше 2')
    else:
        print('a не больше двух')
else:
    print('a не больше 5')
```
Здесь использовались операторы сравнивания '>' (больше) и '<' (меньше).

Также в питоне используются логические операторы 
'!=' (не равно), '<=' (меньше либо равно), '>=' (больше либо равно).
