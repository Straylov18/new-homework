# Объекты в python

Достаточно часто в программе необходимо выполнять какие-то операции 
над одними и теми же группами данных.

В таких случаях часто объединяют функции и переменные в одни сущности - объекты.
Объекты позволяют упростить кода, упростить переиспользование этого кода и 
сделать его более удобным для импортирования.

Переменные, относящиеся к объекту называются атрибутами, 
а его функции - методами.

Для создания объекта необходимо сначала описать специальный шаблон - класс.
Каждый объект это экземпляр класса, 
имеющий свое уникальное состояние (значения атрибутов) 
и может выполнять поведение, определённое в классе (методы).

Названия классов в питоне принято писать в CamelCase стиле.

Создадим класс Computer:
```python
class Computer:
    cores = 2
    ram = 2
    disk_space = 1000
    
    def show_main_parameters(self):
        print(f'{self.cores} ядра, {self.ram}, гига')
```
У него есть атрибуты (cores, ram, disk_space), 
которые имеют значения по умолчанию.
Также у этого класса есть метод show_main_parameters, 
выводящий основные характеристики компьютера
(о том, что в нем происходит чуть позже).

Создадим на основе класса Computer пару объектов 
и произведем с ними некоторые манипуляции:
```python
# создадим компьютер со свойствамии по умолчанию
computer_1 = Computer()

# создадим компьютер и зададим ему cores, ram
computer_2 = Computer()
computer_2.cores = 4
computer_2.ram = 4

# веведем основные характеристики компьютеров при помощи метода, описанного в классе
computer_1.show_main_parameters()  # выведет "2 ядра, 2 гига"
computer_2.show_main_parameters()  # выведет "4 ядра, 4 гига"
```

## Магические методы (окаймленные с нижними подчеркиваниями)

Методы с двумя нижними подчёркиваниями в python 
называются магическими или dunder-методами. 
Это специальные методы, 
с помощью которых можно добавить в классы описание особых событий.

Все магические методы имеют какую-то реализованную логику по умолчанию, 
которую можно переопределить, 
описав этот метод в коде класса.

## Метод перевода в строку

Еще один часто используемый магический метод str 
определяет преобразование объекта в строку.

Добавим этот метод в наш класс:
```python
class Computer:
    cores = 2
    ram = 2
    disk_space = 1000
    color = 'gray'

    def __str__(self):
        return f"строковое представление объекта: ({self.cores}, {self.ram}, {self.disk_space}, {self.color})"

    # other methods
```
Тогда при конвертации объекта этого класса в строку вызовется этот метод:
```python
# воспользуемся магическим методом перевода в строку
computer_4 = Computer(2, 3)
print(computer_4)  # print автоматически вызывает str(computer_1) метод
# выдаст 'строковое представление объекта: (2, 3, 1000, gray)'
```

## Еще несколько примеров магических методов

Вот еще несколько методов, 
которые можно описать через магические функции:

- add - определяет поведение оператора сложения.
- eq - определяет сравнение на равенство.
- len - возвращает длину объекта, полезна для классов, 
которые представляют собой коллекции элементов.
