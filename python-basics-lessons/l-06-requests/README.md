# Парсинг api существующих сайтов

## Отправка REST запросов с помощью библиотеки requests

Для начала установим библиотеку requests:
```shell
pip install requests
```

Для примера сделаем запрос к правительственному сервису США, 
в котором получим список всех школ и какую-нибудь информацию о них.

Для этого сделаем REST запрос к ручке 'https://api.data.gov/ed/collegescorecard/v1/schools', 
передав в нее дополнительные параметры в url через '?'.
Разные REST ручки разных сервисов по-разному принимают входные параметры, 
тут надо смотреть документацию сервисов, к которым ты обращаешься.

Одним из параметров зачастую необходимо передавать ключ пользователя, 
от имени которого должно происходить обращение. 
В нашем случае можно сказать сервису, 
что мы используем тестовый ключ (api_key=DEMO_KEY).

Также в параметрах передадим информацию, 
которую мы хотим получить для каждой школы (&fields=id%2Cname%2Clocation%2Cstudent.size).

При передаче параметров через url они должны разделяться при помощи символа '&'.

Тогда код на получение информации о школа США будет следующим:
```python
import requests

url = 'https://api.data.gov/ed/collegescorecard/v1/schools?api_key=DEMO_KEY&fields=id%2Cname%2Clocation%2Cstudent.size'

response = requests.get(url)

print(response.status_code)
print(response.json())
```
Здесь:
- ```requests.get(url)``` отправляет REST запрос типа GET (аналогично можно отправлять все виды REST запросов ```requests.post(url)```, ```requests.patch(url)```, ...)
- ```response.status_code``` возвращает код ответа запроса
- ```response.json()``` возвращает тело ответа, конвертированное в словарь 

Чтобы выводить значения в красивом формате добавим отступы к выводимому json:
```python
import json

# ... тут код самого запроса ...

print(json.dumps(response.json(), indent=4))
```
