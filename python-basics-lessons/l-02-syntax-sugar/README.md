# Упрощения команд в python

В языке python существует множество конструкций, 
без использования которых можно обойтись, 
но которые при этом делают написание программы сильно удобнее.

Разберем наиболее часто используемые из них.

## Упрощение нарезания листов (слайсы)

Чтобы скопировать часть листа или кортежа, 
обрезав некоторые элементы, 
можно использовать так называемые слайсы.
Они позволяют удобно обрезать листы, 
кортежи или списки с концов:
```python
# изначальный список
initial_list = [0, 1, 2, 3, 4, 5, 6, 7]

# обрезание листа с концов
print('обрезание листа с концов')
# вырежем кусок списка с начала вплоть до пятого элемента (не включительно)
print(initial_list[:5])  # выдаст [0, 1, 2, 3, 4]
# вырежем кусок списка со второго элемента (включительно) до пятого элемента (не включительно)
print(initial_list[2:5])  # выдаст [2, 3, 4]
# вырежем кусок списка со второго элемента (включительно) до конца
print(initial_list[2:])  # выдаст [2, 3, 4, 5, 6, 7]

# индексы элементов также можно указывать с конца
print('обрезание листа с концов (указание индексов с конца)')
# вырежем кусок списка с предпоследнего элемента (включительно) до конца
print(initial_list[-2:])  # выдаст [6, 7]
# вырежем кусок списка с третьего с конца элемента (включительно) до последнего (не включительно)
print(initial_list[-3:-1])  # выдаст [5, 6]

# также можно выбирать шаг, с которым будем проходиться по элементам
print('обрезание листа с выбором шага')
# каждый третий элемент
print(initial_list[::3])  # выдаст [0, 3, 6]
# каждый третий элемент, начиная со второго
print(initial_list[2::3])  # выдаст [2, 5]
# каждый третий элемент, вплоть до предпоследнего (не включительно)
print(initial_list[:-2:3])  # выдаст [0, 3]

# слайсы можно делать не только с листами
print('слайсы на строках и кортежах')

# подобные операции можно делать также со строками
initial_string = '1234567'
# вырежем кусок строки со второго элемента (включительно) до предпоследнего (не включительно)
print(initial_string[2:-2])  # выдаст '345'

# слайсы можно делать и на кортежах
initial_tuple = (0, 1, 2, 3)
# вырежем кусок строки с первого элемента (включительно) до последнего (не включительно)
print(initial_tuple[1:-1])  # выдаст (1, 2)
```

## Работа со строками

В программировании веб приложений очень часто делаются операции со строками.
Далее представлены несколько конструкций, 
позволяющих упрощать написание кода, обрабатывающего строки.

### Составление строк из переменных

Чтобы удобно было собирать текст из кусков, 
не используя сложения и приведения типов, 
можно использовать так называемые **f**-строки:
```python
# удобная компоновка строк из переменных
a = 1
b = 2

# классическое выражение (неудобное)
print("a = " + str(a) + ", b = " + str(b) + ", a+b = " + str(a+b))  # выдаст "a = 1, b = 2, a+b = 3"

# короткое выражение через f-строку (удобное)
# в f-строках можно вставлять значения переменных прямо в середину строки
print(f"a = {a}, b = {b}, a+b = {a+b}")  # выдаст "a = 1, b = 2, a+b = 3"
```

### Объединение итерируемых сущностей в строки с указанием разделителей

Очень часто нужно объединить элементы списка или кортежа в строку, 
разделив их какой-то или символом:
```python
# изначальный список
initial_list = ['str1', 'str2', 'str3']
# объединение элементов списка в строку, разделяя их запятой с пробелом
print(', '.join(initial_list))  # выдаст "str1, str2, str3"

# изначальный кортеж
initial_tuple= ('str1', 'str2', 'str3')
# объединение элементов списка в строку, разделяя их запятой с пробелом
print(', '.join(initial_tuple))  # выдаст "str1, str2, str3"

# разделение символов строк
initial_str = 'qwer'
# разделители между символами строки
print(' '.join(initial_str))  # выдаст "q w e r"
```

## Генерация листов, кортежей и словарей

Очень часто для создания новых списков или фильтрации существующих
в python используют генераторы списков.

**Генераторы списков (List Comprehensions)** в python - 
это синтаксическая конструкция, 
которая позволяет создавать новые списки, 
применяя выражение к каждому элементу указанной последовательности 
(например, списка, строки или диапазона чисел).

Задается генератор следующим образом:
```python
[выражение for переменная in последовательность if условие]
```
где:
- выражение - выражение, применяемое к каждому элементу для создания нового элемента списка;
- переменная - переменная, представляющая каждый элемент последовательности;
- последовательность - итерируемый объект (список, кортеж, строка, range и т. д.);
- условие (необязательно) - фильтрующее условие для включения элемента в результирующий список.

Например:
```python
# получение квадратов чисел из изначальной последовательности
squares = [x**2 for x in range(5)]
print(squares)  # выдаст квадраты четных чисел [0, 1, 4, 9, 16]

# получение квадратов чисел из только четных чисел изначальной последовательности
even_squares = [x**2 for x in range(5) if x % 2 == 0]
print(even_squares)  # выдаст квадраты четных чисел [0, 4, 16]
```

### Генераторы словарей

Аналогичным образом можно генерировать словари:
```python
{ключ: значение for элемент in итерируемый_объект}
```

Например:
```python
# словарь, где ключ - элемент из изначальной последовательности, 
# а значение - квадрат соответствующего числа
squares = {x: x**2 for x in range(5)}
print(squares)  # выдаст {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

### Генераторы кортежей

Аналогичным образом можно генерировать кортежи:
```python
(выражение for элемент in итерируемый_объект if условие)
```
Только данная конструкция вернет генератор, чтобы получить из него кортеж, 
его необходимо обернуть в стандартную функцию "tuple()".

Например:
```python
# получение квадратов чисел из изначальной последовательности и создание генератора кортежей из них
squares_gen = (x**2 for x in range(5))
print(tuple(squares_tuple))  # выдаст (0, 1, 4, 9, 16)
```

## Вычисление суммы элементов последовательности, заданной через генератор

Если необходимо посчитать сумму элементов последовательности, 
не записывая все их в память, 
это тоже можно сделать с помощью генераторов.

Например:
```python
squares_sum = sum(x ** 2 for x in range(5))
print(squares_sum)  # выдаст 30
```

## Лямбда функции

Порой возникает потребность написать однострочную функцию, которая должна будет вызвана единожды.
Зачастую для того, чтобы передать такую функцию в качестве аргумента другой функции.

Для этого в питоне есть специальные лямбда функции (lambda function).
Это специальная анонимная (не нужно именовать) однострочная функция, 
которая автоматически возвращает результат записанного в нее выражения.



В простейшем исполнении она выглядит следующим образом:
```python
lambda входной_параметр1, входной_параметр2, итд: выражение_результат_которого_будет_выдавать_функция
```

Например:
```python
sqr = lambda x: x * x
print(sqr(5))  # выведет 25
```
Здесь мы запихнули лямбда функцию ```lambda x: x * x``` возведения в квадрат в переменную ```sqr```.

Пример с двумы входными параметрами:
```python
add = lambda a, b: a + b
print(add(3, 7))  # выведет 10
```

Также в выражения лямбда функций можно добавлять условия (при помощи тернарных операторов):
```python
max_num = lambda a, b: a if a > b else b
print(max_num(10, 5))  # выведет 10
```

### Примеры применения лямбда функций

Лямбда функции удобно использовать при работе с листами.

Например, чтобы поставить в соответствие каждому элементу листа какой-то другой:
```python
numbers = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, numbers))
print(doubled)  # выведет [2, 4, 6, 8]
```
А можно быстро напистаь фильтр для листа: 
```python
numbers = [1, 2, 3, 4, 5, 6]
even = list(filter(lambda x: x % 2 == 0, numbers))
print(even)  # выведет [2, 4, 6]
```
Можно использовать при сортировке:
```python
words = ['11', 'qweqwe', 'e']
sorted_words = sorted(words, key=lambda x: len(x))
print(sorted_words)  # выведет ['e', '11', 'qweqwe'] (отсортированные по длине)
```

Также существует множество полезных функций во встроенной библиотеке **functools**, 
где удобно использовать лямбда функции.
Например, чтобы последовательно посчитать какую-то метрику, учтя все элементы листа:
```python
from functools import reduce
numbers = [1, 2, 3, 4]
product = reduce(lambda x, y: x * y, numbers)
print(product)  # выведет 24 (1*2*3*4 = 24)
```
