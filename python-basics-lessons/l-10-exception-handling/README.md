# Исключения в python

Исключения (exception) - это специальные события, 
которые прерывают выполнения программы.
Они вызываются (или же их принято вызывать), 
когда произошла какая-то ошибка, которая ломает логику программы.

## Обработка исключений операторами try, catch, finally

Напишем код, который может вызывать ошибки во время его работы.
Допустим просто деление двух чисел:
```python
a = 42
b = input('ну-ка введи что-нить сюда: ')
print(a / int(b))
```

Сейчас если пользователь введет 0, 
программа свалится с ошибкой и не пойдет дальше 3-й строки.

Мы можем отлавливать такого рода ошибки с помощью try catch конструкций:
```python
a = 42
b = input('ну-ка введи что-нить сюда: ')
try:
    # тут пишем код, в котором потенциально могла бы быть ошибка
    print(a / int(b))
except ZeroDivisionError:
    # тут пишем что нужно делать, если произошло деление на ноль
    print('Нельзя делить на ноль ..')
```
Здесь:
- все, что помещено внутрь try будет проверяться на наличие ошибок
- если внутри будет исключение ZeroDivisionError, 
то отработает код из блока ```except ZeroDivisionError:```, 
после чего программа продолжит выполняться дальше

Однако из-за действий пользователя могут появиться и другие ошибки, 
например невозможность конвертации типов.

Обработаем и такие ошибки:
```python
a = 42
b = input('ну-ка введи что-нить сюда: ')
try:
    # тут пишем код, в котором потенциально могла бы быть ошибка
    print(a / int(b))
except ZeroDivisionError:
    # тут пишем что нужно делать, если произошло деление на ноль
    print('Нельзя делить на ноль ..')
except ValueError:
    # тут пишем что нужно делать, если невозможно произвести операцию с введенным типом данных
    print('Надо было вводить число)')
```
Здесь оба вида ошибок будут обрабатываться в отдельном блоке.

Мы можем также обработать все виды остальных ошибок 
при помощи общего класса ошибок Exception 
(от которого унаследованы все остальные):
```python
a = 42
b = input('ну-ка введи что-нить сюда: ')
try:
    # тут пишем код, в котором потенциально могла бы быть ошибка
    print(a / int(b))
except ZeroDivisionError:
    # тут пишем что нужно делать, если произошло деление на ноль
    print('Нельзя делить на ноль ..')
except ValueError:
    # тут пишем что нужно делать, если невозможно произвести операцию с введенным типом данных
    print('Надо было вводить число)')
except Exception:
    # тут пишем что нужно делать, если произошла любая другая ошибка (в самом крайнем случае пишем)
    print('Что-то пошло не так! Хто я? Де я?')
```

Не стоит всегда обрабатывать все типы ошибок, 
лучше сперва обрабатывать только те, которые ты ожидаешь, 
и уж в крайнем случае все остальные.

Также можно указать действия которые должны выполниться так или иначе 
(вне зависимости от наличия ошибок) в самом конце всех операций.
Сделать это можно при помощи конструкции finally:
```python
a = 42
b = input('ну-ка введи что-нить сюда: ')
try:
    # тут пишем код, в котором потенциально могла бы быть ошибка
    print(a / int(b))
except ZeroDivisionError:
    # тут пишем что нужно делать, если произошло деление на ноль
    print('Нельзя делить на ноль ..')
except ValueError:
    # тут пишем что нужно делать, если невозможно произвести операцию с введенным типом данных
    print('Надо было вводить число)')
finally:
    # этот код исполнится всегда в самом конце выражения
    # вне зависимости от того, выкинулось ли какое-либо исключение или же все отработало штатно
    # обычно используется, чтобы закрыть доступы к ресурсам (при чтении файла там)
    print('Так или иначе выполняется после всего этого (вне зависимости от того, есть ошибка или нет)')
```

Если это все происходит внутри функции, 
то принято не писать return внутри finally, 
поскольку тот будет перебивать return из try.

## Оператор raise

Помимо системных исключений ты можешь поднимать свои 
в тот момент времени, когда тебе захочется, 
при помощи оператора **raise**.

Например поднимем исключение, если пользователь ввел '69':
```python
a = 42
b = input('ну-ка введи что-нить сюда: ')

try:
    print(a / int(b))
    if b == '69':
        raise Exception('сами вывели ошибку')
except Exception:
    # отработает этот код
    print('Что-то пошло не так! Хто я? Де я?')
```

## Получение информации об ошибке

В блоке **except** мы можем также получить информацию об ошибке:
```python
a = 42
c = input('еще разок: ')

try:
    print(a / int(c))
except Exception as e:
    print(e)
```
Здесь:
- при помощи ```except Exception as e``` объект ошибки присваивается переменной e,
которая будет доступна в блоке ```except```
- при помощи ```print(e)``` выводиться текстовое представление ошибки 

## Создание своих классов исключений

Также ты можешь создавать свои классы исключений, 
чтобы делать обработку конкретно их в случае чего.

Для этого необходимо просто унаследовать свое исключение от другого класса исключений, 
например от базового:
```python
class Exception69(Exception):
    pass
```

Тогда использовать его можно также как и все остальные исключения:
```python
d = input('не вводи 69: ')

try:
    if d == '69':
        raise Exception69('Текст ошибки')
except Exception69 as e69:
    print('успешно перехватили ввод 69')
    print(e69)  # выведет 'Текст ошибки'
```

Стоит помнить, что в **except** исключение вызывается, 
если класс исключения равен указанному в **except**, 
или если вызванное исключение унаследовано от указанного класса в **except**. 
Собственно поэтому ```except Exception``` будет обрабатывать все виды исключений, 
ведь все они унаследованы в конечном итоге от него.
