# Пакеты и импорты в python

При написании больших приложений на python принято разделять код по разным файлам, 
чтобы его было легче читать.

## Использование кода из других файлов

Чтобы использовать переменные, функции итд. из других файлов, 
их необходимо сначала импортировать.
Предположим у нас есть файл **sub_package/file_for_imports.py**:
```python
cities = {
    "Moscow": 12,
    "St.Petersburg": 5,
    "Vladivostok": 13,
    "Novosibirsk": 1.5,
    "Krasnoyarsk": 1,
}


def print_city_population(city_name):
    if cities.get(city_name, None) is not None:
        print(f"население {city_name}: {cities[city_name]}")
    else:
        print(f"города {city_name} нет в базе данных")
```

Мы можем использовать функцию print_city_population из файла **sub_package/file_for_imports.py**
в других местах программы, предварительно импортировав ее.
Например используем эту функцию в другом фале **main.py**:
```python
from sub_package.file_for_imports import print_city_population

# вызываем импортированную функцию
print_city_population("Novosibirsk")
print_city_population("New-York")
```
Здесь в строчке 
```python
from sub_package.file_for_imports import print_city_population
```
указано откуда (from sub_package.file_for_imports) и что (import print_city_population) мы хотим импортировать.
Путь к файлу при импорте пишется относительно той папки, из которой этот файл импортируется.

## Пакеты в python

Чтобы было легче группировать уже большое количество файлов с кодом, эти файлы объединяют в **пакеты**.
**Пакет в python** - это по сути просто папка с **__init__.py** файлом внутри нее.
Принято класть **__init__.py** файл по умолчанию во все папки с питоновскими фалами, чтобы они были пакетами.

### Зачем нужны __init__.py файлы

Код, написанный в **__init__.py** файле будет вызываться при импорте чего-то из папки, 
в которой лежит **__init__.py** файл.
Например, если написать в **sub_package/__init__.py** следующий код:
```python
print("этот вывод отрабатывает при импорте из пакета sub_module")
```
то при импорте функции из фалов внутри **sub_module**
```python
from sub_package.file_for_imports import print_city_population
```
будет выводиться сообщение.

Это необходимо для того, чтобы можно было прописать какие-то действия 
перед каждым использованием конкретного пакета.
Однако в большинстве случаев эти **__init__.py** файлы остаются пустыми.

## Как проверить через какой файл запускалась программа

Обычно проекты на python принято запускать через **main.py** файлы.
Однако, чтобы убедиться, что **main.py** файл был именно запущен, а не импортирован, 
часто пишут следующее условие:
```python
if __name__ == '__main__':
    print("запустили main.py")
    # тут пишется код, который необходимо выполнять при обособленном старте приложения
else:
    print("main.py импортировали")
```

Эту конструкцию ты часто будешь встречать в приложениях.
