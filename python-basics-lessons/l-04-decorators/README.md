# Декораторы

Декоратор в Python — это функция, 
которая принимает другую функцию в качестве аргумента, 
расширяет или изменяет её поведение и возвращает изменённую функцию 
без изменения исходного кода. 

Декораторы позволяют оборачивать функции дополнительной логикой, 
сохраняя при этом оригинальную функцию и её данные.

Создадим функцию, которая видоизменяет другую функцию:
```python
def some_decorator(func):
    def wrapper():
        print('выводиться перед вызовом функции')
        func()
        print('выводиться после вызова функции')
        
    return wrapper
```

Чтобы применить этот декоратор к какой-то функции, 
необходимо написать @some_decorator перед именем оборачиваемой функции:
```python
@some_decorator
def some_func_1():
    print('some_func_1')


@some_decorator
def some_func_2():
    print('some_func_2')
```

Теперь при вызове функций будет вызываться дополнительный код, 
описанный в декораторе:
```python
some_func_1()  # выведет текст из комментариев ниже:
# выводиться перед вызовом функции
# some_func_1
# выводиться после вызова функции
some_func_2()  # выведет текст из комментариев ниже:
# выводиться перед вызовом функции
# some_func_2
# выводиться после вызова функции
```

## Декораторы с доп параметрами

В декоратор также можно передавать дополнительные параметры при его вызове.
Для этого необходимо обернуть декоратор, обрабатывающий функцию в еще один декоратор:
```python
def hello_decorator(n):
    def actual_decorator(func):
        def wrapper():
            for i in range(n+1):
                print('выводиться перед вызовом функции')
            result = func()  # вызов оригинальной функции
            return result
        return wrapper
    return actual_decorator


@hello_decorator(3)
def some_func_3():
    print('some_func_3')


@hello_decorator(2)
def some_func_4():
    print('some_func_4')


some_func_3()  # выведет текст из комментариев ниже:
# выводиться перед вызовом функции
# выводиться перед вызовом функции
# выводиться перед вызовом функции
# выводиться перед вызовом функции
# some_func_3
some_func_4()  # выведет текст из комментариев ниже:
# выводиться перед вызовом функции
# выводиться перед вызовом функции
# some_func_4
```
