# Все, что нужно знать, чтобы подключаться к серверу и работать на нем из консоли

Большая часть серверов не имеет визуальных интерфейсов, 
поэтому чтобы сделать какие-то операции на сервере, 
разработчикам зачастую необходимо пользоваться консолью.
Для безопасного удалённого управления сервером из консоли люди придумали специльный протокол **ssh** (Secure Shell).
Этот протокол позволяет подключиться к серверу под определенным пользователем 
и испольнять консольные команды на нем.

Поскольку веб приложения разворачиваются на серверах (как фронт, так и бэк), 
разработчикам необходимо иметь представление о том, 
как производить базовые манипуляции с серверами.

## Подключение по ssh впервые

Чтобы подключиться по ssh нужно указать имя пользователя, под которым ты будешь работать на сервере и адрес сервера:
```shell
ssh пользователь@адрес_сервера
```
Адрес сервера может быть как доменом (например example.com), 
так и IP адресом (например 188.47.195.201).

Если ты подключаешься к этому серверу впервые, то увидешь следующий текст:
```
The authenticity of host 'адрес_сервера (адрес_сервера)' can't be established.
ECDSA key fingerprint is SHA256:KOx9T7VeRy9dJ2ug+tfnlbnG/7Fm0I5Tl/ziTkE4JaE.
Are you sure you want to continue connecting (yes/no)? 
```
В таком случае необходимо ввести "yes".

Потом если на сервере разрешен вход по паролю, 
он спросит пароль от пользователя, под которым ты пытаешься зайти, и пустит тебя внутрь.
Если ты успешно зашел на сервер, 
то все команды твоей консоли теперь выполняются непосредственно на сервере.

Чтобы выйти с сервера можно нажать **Ctrl+D**. Тогда ты вернешься в консоль локального компьютера.

## Подключение по ключу

В большинстве случаев лучше входить используя специальные ключи шифрования:
- не нужно каждый раз вбивать пароль
- это безопаснее
- на сервере может быть отключен вход по паролю, тогда это вообще твоя единственная опция

## Порты

Если ты не указываешь порт (как мы делали выше, он указывается автоматически как 22-й).
Порой сервер имеет нестандартный порт, его можно указать через параметр **-p**:
```shell
ssh пользователь@адрес_сервера -p 22
```

## Загрузка файлов на сервер, с сервера

Также ты можешь загружать файлы на сервер по ssh и выгружать их оттуда при помощи команды **scp**.
Чтобы загрузить файл на сервер:
```shell
scp путь_к_локальному_файлу пользователь@адрес_сервера:путь_к_файлу_на_сервере
```
Чтобы скачать файл с сервера:
```shell
scp пользователь@адрес_сервера:путь_к_файлу_на_сервере путь_к_локальному_файлу
```

## Удобное хранение списка серверов

Чтобы не вбивать каждый раз имя пользователя, порт, адрес, для каждого сервера 
и не запоминать это все для каждого сервера, 
ты можешь один раз сохранить эту информации в файле **~/.ssh/config**. 
А потом подключаться только по заданным тобой названиям.

Например добавим в этот файл информацию о двух серверах:
```shell
Host удобное_имя_сервера_1
Hostname адрес_сервера_1
User пользователь_на_сервере_1
Port 22

Host удобное_имя_сервера_2
Hostname адрес_сервера_2
User пользователь_на_сервере_2
Port 4242
```
Тогда, чтобы подключаться к первому серверу, ты сможешь просто выполнять команду:
```shell
ssh удобное_имя_сервера_1
```
а для того, чтобы подключаться ко второму серверу:
```shell
ssh удобное_имя_сервера_2
```
