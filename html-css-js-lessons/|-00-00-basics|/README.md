## Frontend Dev

Фронтенд-разработчик — это специалист, который создает **видимую** и **интерактивную** часть веб-приложений, с которой пользователи взаимодействуют напрямую.

Главная задача фронтендера — превратить дизайн-макет в _живой, отзывчивый и удобный инструмент_, как, например, интернет-магазин, где можно выбирать товары, добавлять их в корзину и оформлять заказ.

### Что конкретно делает фронтенд-разработчик?

🔹 **Верстает интерфейсы** — превращает картинки из Figma в строки кода, где описаны правила расположения всех элементов, их цвета и т.п.  
🔹 **Адаптирует под устройства** — чтобы сайт одинаково круто выглядел на телефоне, планшете и мониторе  
🔹 **Программирует логику** — чтобы кнопки нажимались, корзина считалась, а модальные окна открывались  
🔹 **Дружит с бекендом** — отправляет данные на сервер и получает их обратно  
🔹 **Оптимизирует** — чтобы сайт грузился быстро и не бесил пользователей медленной загрузкой

## Три кита веб-разработки (на пальцах)

Представь, что веб-страница — это **человек**.

### 🏗️ HTML — это _скелет_

Создает структуру: где голова, где руки, где ноги. Расставляет элементы по местам — заголовки, картинки, кнопки, списки.  
_Без HTML у тебя просто пустота и нечего будет отображать_

### 🎨 CSS — это _внешность_

Отвечает за красоту: цвета, размеры, шрифты, тени, расположение на странице. Делает из голого скелета ухоженного человека со стилем.  
_Без CSS страница выглядит как из 90-х. Просто текстовый документ с картинками_

### ⚡ JavaScript — это _мозги и мышцы_

Добавляет логику и движение. Реагирует на клики, считает, открывает меню, показывает уведомления, общается с сервером.  
_Без JS страница просто красивая картинка, на которую можно смотреть, но с ней нельзя взаимодействовать._

---

### Коротко:

- **HTML** — говорит **ЧТО** показать
- **CSS** — говорит **КАК** это выглядит
- **JavaScript** — говорит **ЧТО ПРОИСХОДИТ**, когда пользователь тыкает

## Практика

Пойдем по порядку. Первый на очереди: **html**

С него начинается разработка любого веб-приложения. Зададим "скелет" для условной `карточки товара`. Представим, что возводим интернет - магазин.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>

  <body>
    <div class="card">
      <img
        src="https://avatars.mds.yandex.net/get-mpic/15462703/2a00000197e6e53132f8cf7296134d79fb14/orig"
        alt=""
      />
      <h3>Лабубу тропическая</h3>
      <p><strong>1999р</strong></p>
      <button>Купить сейчас</button>
    </div>
  </body>
</html>
```

Самые наблюдательные заметят, что каждый элемент обернут в какие то треугольные скобки.🤔

Это `теги`, основная концепция html разметки. Каждый подобный _тег_ имеет свое назначение, оно может иметь совершенно разный посыл. Ссылка, заколовок, шапка, таблица, список, и тд и тп. Если почитать наполнение некоторых тегов, можно логически понять, что он на странице означает. `<h3>Лабубу тропическая</h3>` - заголовок, `<button>Купить сейчас</button>` - кнопка, призывающая купить. С html подробнее мы познакомимся на следующих уроках.

#### CSS

Навалим стиля! Добавим новый блок, прямо под `</body>`.

```html
<body>
  <!-- ... -->
</body>

<style>
  .card {
    font-family: "Segoe UI";
    width: fit-content;
    background-color: rgb(170, 96, 0);
    padding: 10px;
    border-radius: 20px;
  }
  .card img {
    width: 200px;
    border-radius: 20px;
  }
  .card h3,
  p {
    margin: 5px 0;
  }
  .card button {
    width: 100%;
    border: 0;
    border-radius: 20px;
    background-color: rgb(255, 185, 93);
  }
  .card button:active {
    background-color: rgb(255, 208, 146);
  }
</style>
<html />
```

Здесь мы уже описываем, как будет выглядеть элемент. Т е `.card img{...}` - это _селектор_, чтобы достать до какого то конкретного элемента, а свойства по типу `background-color: rgb(255, 208, 146);` - цвет заднего фона, `border-radius: 20px;` - радиус закругления элемента, и т.д. Конкретно свойств в css очень много, полностью их выучить займет долгое время. Поэтому будем разбираться по ходу. В следующих сериях...🌚

## JS

Джаваскрипт - отвечает за интерактивность на сайте. Он следит за состояниями элементов, работает с информацией, позволяет делать, чтобы при нажатии на одну кнопочку, появилось окошечко, в окошечке есть другая кнопочка, которая тоже имеет какой то функционал, и тд. Сейчас сделаем возможность потратить все наши деньги на Лабубу!

#

Между `<html/>` и `<style>` сделаем еще одну секцию `<script>` и наполним ее следующим:

```html
<html>
  <body>
    <!-- ... -->
  </body>

  <script>
    let balance = 10000; // изначальный баланс пользователя

    function buyALabubu(cost) {
      // функция, обертка для кода, чтобы можно было ее вызвать
      if (balance >= cost) {
        // проверяем, хватает ли денег на покупку
        balance -= cost; // вычитаем стоимость из баланса
        alert("Покупка успешна! Ваш новый баланс: " + balance); // уведомляем пользователя об успешной покупке и показываем новый баланс
      } else {
        alert("Недостаточно средств для покупки! Ваш баланс: " + balance); // уведомляем пользователя о недостатке средств и показываем текущий баланс
      }
    }
  </script>

  <style>
    /* ... */
  </style>
</html>
```

Пожалуйста, теперь у нас есть функция, написанная на js, которая поэтапно выполняет все действия, чтобы прийти к какому то результату.
Js - тоже очень интересная штука, которую ты учишь еще долго после того как вышел на уровень того же джуна

#

Теперь, присвоим нашу фунукию к кнопке, следующим образом:

```html
<button onclick="buyALabubu(1999)">Купить сейчас</button> 
```

Теперь, при нажатии на кнопку, у нас будет на экран выводиться уведомление об успешной покупке(если у накс хватает денег). 
Если денег не хватит, об этом тоже уведомит сайт. Благодаря условному оператору `if - else`. Но подробнее об этом тоже потом)))
