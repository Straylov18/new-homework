# JavaScript - логика сайта и интерактивность
## Что это вообще такое и какая необходимость в нем?

**JavaScript** — это язык программирования, который *вдыхает жизнь* в сайт и делает его **интерактивным**.

| Роль | Технология | Аналогия |
|------|------------|----------|
| Структура | **HTML** | 🦴 *Скелет* (заголовки, кнопки) |
| Стиль | **CSS** | 🎨 *Внешний вид* (цвета, шрифты) |
| Поведение | **JavaScript** | 🧠 *Мышцы и мозг* (реакция на действия) |

> JavaScript объясняет сайту, что делать, когда ты **нажимаешь на кнопки**, **вводишь текст** или **скроллишь страницу**.

### 🔑 Ключевая концепция — работа с информацией
- Сбор данных (например, из формы)
- Проверка (валидация)
- Отправка и получение данных с сервера

### 💡 Универсальность
Язык не привязан только к странице: на JavaScript можно писать и **серверную часть (бэкенд)**, создавая полноценные приложения.

## 📦 Переменные — коробки для информации

 **Переменная** — это подписанная коробка, в которую можно положить какое-то значение, чтобы потом использовать его в программе. Вместо того чтобы помнить «вон ту длинную фразу или число», мы просто кладём их в коробку с понятным именем и обращаемся к ней когда нужно.

Представь гардероб в музее: ты сдаёшь рюкзак, а взамен получаешь **номерок**. По этому номерку позже можно получить свой рюкзак обратно. Переменная работает так же — через имя мы сохраняем и достаём данные.

---

### Типы переменных в современном JavaScript

**`const`** — константа (коробка на замке)

Значение нельзя перезаписать после создания. Идеально для всего, что не должно меняться.

```js
const имяПользователя = "Анна";
const годРождения = 1995;
```

**`let`** — изменяемая переменная (коробка без замка)

Значение можно обновить в любой момент. Подходит для счётчиков, состояния, вводимых данных.

```js
let счётчик = 0;
счётчик = 1; // так можно
``` 

Раньше использовали ещё `var`, но сейчас его стараются избегать — у него хитрое, часто неожиданное поведение, которое новичкам только мешает.

## 🧵 Конструктор строк и вывод в консоль

### Шаблонные строки — `...${...}...`

Когда нужно собрать строку из текста и переменных, используют **обратные кавычки** и конструкцию `${...}`:

```js
const имя = "Анна";
const возраст = 28;

const приветствие = `Привет, меня зовут ${имя} и мне ${возраст} лет`;
```

Внутри `${}` можно поместить любую переменную или даже выражение — JS сам превратит это в текст и вклеит в строку. Это гораздо удобнее, чем склеивать куски через плюсы.

### Консоль — рабочий стол разработчика

**Консоль** — это невидимый для обычного пользователя экран, куда программа может печатать сообщения. Разработчик открывает её через `F12` → вкладка Console и видит, что происходит внутри кода: ошибки, значения переменных, результаты вычислений.

Основная команда — `console.log()`:

```js
console.log(приветствие); // "Привет, меня зовут Анна и мне 28 лет"
console.log(2 + 2); // 4
console.log("Всё работает!"); // "Всё работает!"
```

Это главный инструмент для проверки и отладки: вывел в консоль — увидел, что лежит в переменной, и сразу понял, где ошибка.

### 2. Калькулятор скидки
В переменной `цена` лежит 2000, в переменной `скидка` — 15 (процентов). Посчитай итоговую стоимость и выведи в консоль фразу: `"Цена со скидкой: ... рублей"`. Внутри `${}` должно быть выражение, а не готовое число.

### 3. Найди ошибку
Ниже код, который должен вывести `"Мне 25 лет"`, но он не работает. Найди и исправь ошибку:

```js
const возраст = 25;
возраст = 26;
console.log("Мне " + возраст + " лет");
```

### 4. Конструктор автоподписи
Создай переменные `должность`, `имя`, `компания`. Собери из них автоподпись для email такого вида:

```js

```

Выведи в консоль три варианта подписи, меняя только значения переменных (сам `console.log` трогать не нужно).
