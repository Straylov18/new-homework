# JavaScript - if/else и проверка условий.
Привет! Рад, что ты продолжаешь свой путь в JavaScript. Сегодня мы познакомимся с одной из самых важных концепций программирования — **проверкой условий и конструкцией `if/else`**. Без этого инструмента код был бы просто скучной последовательностью действий, а с ним он учится «думать» и принимать решения. Давай разбираться.

## Что это вообще такое и зачем проверять условия?

Представь, что код — это твой помощник. Но он очень прямолинейный и делает всё строго по инструкции. Как ему объяснить, что для разных покупателей в интернет-магазине нужно показывать разные товары: мужскую или женскую одежду, обувь разного размера?

Именно для этого и нужны **условия**. Это как вопрос, на который можно ответить только «да» (в программировании — `true`) или «нет» (`false`). В зависимости от ответа ты можешь направить своего помощника-код по одному или другому пути:

*   «**Если** пользователь — мужчина, **то** показываем раздел с мужскими кроссовками. **Иначе** показываем раздел с женскими».
*   «**Если** сумма в корзине больше 2000 рублей, **то** делаем скидку 10%».
*   «**Если** пароль введен верно, **то** показываем приветственное окно. **Иначе** выводим сообщение об ошибке».

Такое разветвление в коде называется **ветвлением**, а сама конструкция `if/else` — твой главный инструмент для этого.

## Пример кода

Давай сразу посмотрим, как это выглядит в коде. Представь, что мы пишем простую проверку возраста для входа на сайт.

```js
let age = 20;

if (age >= 18) {
  console.log('Добро пожаловать! Вы можете войти на сайт.');
} else {
  console.log('Извините, доступ разрешён только с 18 лет.');
}
```

### Объяснение

Разберём по шагам, что здесь происходит:

1.  `let age = 20;` — Ты уже знаком с переменными. Здесь мы просто создаём переменную `age` (возраст) и кладём в неё число 20.
2.  `if (age >= 18) { ... }` — Это и есть наша **проверка условия**.
    *   `if` — ключевое слово (переводится как «если»).
    *   `(age >= 18)` — само **условие**. Мы спрашиваем: «Переменная `age` больше или равна 18?».
        *   `>=` — это **оператор сравнения** («больше или равно»). Он даёт ответ `true` (правда) или `false` (ложь).
    *   `{ ... }` — **блок кода**, который выполнится, если ответ `true`.
3.  `else { ... }` — Эта часть переводится как «иначе». Блок кода внутри `else` сработает, если условие в `if` оказалось ложным (`false`).
4.  `console.log(...)` — Это команда, которая выводит текст в консоль браузера.

**Что произойдёт:** Так как `age` равно 20, а `20 >= 18` — это правда (`true`), то выполнится код в блоке `if`, и в консоли мы увидим: **«Добро пожаловать! Вы можете войти на сайт.»**.

Попробуй мысленно поменять в коде `let age = 20;` на `let age = 15;`. Условие `age >= 18` станет ложью (`false`), и выполнится уже блок `else`, показав сообщение об отказе в доступе.

## Задание на практику

Теория — это хорошо, но лучший способ понять — попробовать самому. Вот несколько идей, которые ты можешь проверить прямо в консоли своего браузера (нажми F12 и перейди на вкладку "Console"):

1.  **Погодный совет**: Создай переменную `temperature` (температура). Напиши условие: если температура ниже 15 градусов, выводить сообщение «Холодно, надень куртку». В противном случае — «Тепло, можно идти в футболке». Попробуй присваивать `temperature` разные значения (10, 20, 15).
2.  **Проверка пароля**: Сохрани в переменную `secretPassword` строку `'js-супер'`. Создай ещё одну переменную `userInput` и присвой ей любое значение, например `'просто пароль'`. Сравни их. Если значения совпадают, выводи «Секретный доступ разрешён!», а если нет — «Неверный пароль!».
3.  **Вечерний свет**: Создай переменную `hour` и задай ей текущее время (например, 20). Напиши проверку: если значение `hour` больше 18 ИЛИ меньше 6, выводи «На улице темно». В противном случае — «На улице светло».

Это отличный способ прочувствовать, как работают условия, на очень простых примерах.

## Типы данных и чем отличается === от ==

В примере с паролем мы будем использовать **строгое сравнение** `===` (три знака равенства). Почему не два? Разница очень важна:

*   `==` (нестрогое равенство): Пытается превратить («привести») значения к одному типу данных перед сравнением. Например, `5 == '5'` будет `true`, так как строка `'5'` превратится в число `5`. Это может приводить к неожиданным ошибкам.
*   `===` (строгое равенство): Сравнивает и значение, и его тип. Никаких превращений. Поэтому `5 === '5'` будет `false`, ведь число и строка — это разные типы данных.

**Хорошее правило для начинающих:** Всегда используй `===` (и `!==` для проверки на неравенство), если у тебя нет особой причины поступать иначе. Так ты будешь уверен в предсказуемости своих проверок.
