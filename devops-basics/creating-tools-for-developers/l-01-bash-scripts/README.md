# Введение в bash скрипты

**Bash-скрипт** - это файл с последовательностью команд, 
которые компьютер выполняет по очереди, строка за строкой. 
Это позволяет автоматизировать повторяющиеся задачи. 

Bash скрипты работаю в bash консолях (на MacOS, Linux, WSL, GitBash, итд.).
Для автоматизации под Windows есть аналогичный инструмент - bat скрипты.
Но в web разработка происходит преимущественно под Linux сервера, 
поэтому и разработчики зачастую пользуются bash скриптами.

Представим ситуацию, 
когда для запуска приложения разработчик должен последовательно выполнить несколько команд.
Чтобы не вводить каждый раз все команды, их можно просто прописать в bash скрипте и вызывать его.

## Наиболее частые случаи применения

Зачастую их пишут для каких-то сборок/запусков частей проекта, набивки данными, запуска проверок итд.

## Почему базовый язык для подобных задач именно bash, а не python, go, итд.

Для подобных задач подходят и другие скриптовые языки, 
но их выбор зачастую связан с тем, 
что вся команда неплохо владеет этим языком.

Bash же наиболее удобен для запуска групп консольных команд, 
поскольку является нативным для unix-подобных консолей.
Плюс ко всему он достаточно понятен существенной части разработчиков.

## Первый bash скрипт

Bash скриптам принято делать расширение **.sh**.
Создадим простейший скрипт **first_bash_script.sh**.

Чтобы система понимала с помощью чего нужно интерпретировать скрипт, 
необходимо первой строчкой прописывать ссылку на bash интерпретатор текущей системы. 
```shell
#!/usr/bin/env bash
```

Дальше можно писать команды, любые команды, которые работают в bash консоли.
Например, для вывода сообщений используется команда **echo**:
```shell
echo "Hello world"
```

Напишем также команду для вывода текущей директории:
```shell
pwd
```

Тогда итоговый скрипт **first_bash_script.sh** будет выглядеть следующим образом:
```shell
#!/usr/bin/env bash

echo "Hello world"
pwd
```

Этот скрипт будет выводить сначала "Hello world", а потом текущую директорию.

Комментарии в bash задаются через '#':
```shell
# следующая строка выводит 123
echo "123"
```

### Запуск bash скриптов

Чтобы запустить bash скрипт, необходимо, чтобы файл скрипта имел разрешения на запуск (execute).
Если таковых разрешений нет, их можно задать:
```shell
chmod +x first_bash_script.sh
```
Здесь мы командой **chmod** добавляем для всех пользователей разрешение на запуск (исполнение) файлу.
В случае, если он имеет корректные разрешения 
(см. как читать разрешения фалов в bash консоли), 
запустить его можно просто по имени файла:
```shell
first_bash_script.sh
```

Или чтобы переменные скрипта остались в памяти консоли, можешь запускать его:
```shell
. first_bash_script.sh
# что равносильно 
source first_bash_script.sh
```

## Переменные в bash

В bash все переменные хранят свои значения в виде строки, 
поэтому при операциях с другими типами данных зачастую нужно делать проверки на правильность формата данных.
Задать переменную можно следующим образом:
```shell
variable="hello world"
```
Переопределяется она так же.
Если переменная не была задана, то при ее вызове она будет равна пустой строке.

Чтобы получить значение переменной, к ее названию нужно добавить "$":
```shell
variable_1="var1"
# зададим переменной variable_2 значение "var1var1"
variable_2="$variable_1$variable_1"
```

Чтобы положить в переменную результат выполнения команды необходимо обернуть команду в "$()".
Так, запись пути текущей папки в переменную будет выглядеть следующим образом:
```shell
current_path="$(pwd)"
```

При обработке результатов выполнения команд и получении значения переменных 
следует использовать двойные кавычки, 
чтобы избежать интерпретации результатов как синтаксиса другой bash команды.

## Работа с файлами

Очень часто bash скрипты использую для работы с файлами.
Вспомним некоторые команды для работы с файлами из консоли:
```shell
# удаление файла
rm file
# удаление папки
rm -r dir

# перемещение/переименование файла
mv old/file new/file/path

# копирование файлов
cp old_file file_copy

# чтение текста файла
cat file_name
# чтение текста файла в переменную
file_text="$(cat file_name)"
```

## Функции

В bash скриптах объявление функции равносильно объявлению команды, которую можно исполнять ниже.

Пример объявления и использования функции:
```shell
function show_pwd_twice() {
  pwd
  pwd
}

show_pwd_twice
```

Пример использования функции с параметрами:
```shell
function show_error_message() {
  message=$1
  echo -en "\e[1;31m(ERROR) $message\e[0m\n"
}

show_error_message "error message"
```
Тут получение параметров точно такое же, 
как получение параметров запуска bash скрипта 
($1 - первый порядковый параметр, $2 - второй, итд.).
