# Периодические задачи на сервере (cron задачи)

Порой возникает потребность выполнять одни и те же действия на сервере с определенной периодичностью.
Это может быть полезно для создания бэкапов базы данных, периодических рассылок, 
чисти кешей, обновления сертификатов и ключей безопасности итд.
Для этого в unix-подобных системах (linux, macos) существуют специальные cron задачи, 
позволяющие запускать одни и те же программы с заданной периодичностью.

## crontab

Чтобы система выполняла cron задачу ее надо внести в таблицу активных крон задач.

Отредактировать таблицу cron задач текущего пользователя 
(для каждого пользователя она своя) можно следующей командой:
```shell
crontab -e
```

Таблица cron задач может выглядеть примерно следующим образом:
```
## ... some explanation here ...
# описание зачем добавлена 1-я задачка
1/2 * * * * /bin/bash /etc/cron.hourly/task1.sh 
# описание зачем добавлена 2-я задачка
30 5 * * * /bin/bash /etc/cron.daily/task2.sh 
# описание зачем добавлена 3-я задачка
30 5 1 * * /bin/bash /etc/cron.monthly/task3.sh 
```

Здесь каждая не закомментированная строка 
(комментарий задается через #)
описывает одну команду, которая запускается по соответствующему таймеру.

Разберем формат задач в этой таблице:
```
* * * * * выполняемая команда
- - - - -
| | | | |
| | | | ----- день недели (0—7) (воскресенье = 0 или 7)
| | | ------- месяц (1—12)
| | --------- день месяца (1—31)
| ----------- час (0—23)
------------- минута (0—59)
```

Для создания гибких расписаний система использует несколько специальных символов:
- Звёздочка (*) означает «любое значение» — если поставить её в поле часов, задача будет выполняться каждый час.
- Запятая (,) разделяет несколько конкретных значений. Например, «1,15,30» в поле минут означает выполнение в 1-ю, 15-ю и 30-ю минуты.
- Дефис (-) указывает диапазон. Запись «9-17» в поле часов означает выполнение каждый час с 9:00 до 17:00.
- Косая черта (/) задаёт интервал повторения. Конструкция «*/15» в поле минут означает «каждые 15 минут».

Так, например:
- таймер '1/2 * * * *' будет запускать программу каждую вторую минуту
- таймер '1/2 * 1 * *' будет запускать программу каждую вторую минуту (но только в первый день месяца)
- таймер '1/2 * * * 1' будет запускать программу каждую вторую минуту (но только по понедельникам)
- таймер '30 5 1 * *' будет запускать программу в 5 30 в первый день месяца

Чтобы освоиться с форматом cron задач
(или проверить какую-то периодическую задачу)
можно поиграться на следующем сайте:
https://crontab.guru.

## Примеры использования

Допустим у нас есть bash скрипт, который выводит текущую минуту **~/each_minute_script.sh**:
```shell
#!/usr/bin/env bash
echo $(date +%M)
```

Тогда, чтобы запускать этот скрипт каждую минуту 
и выводить его текстовый вывод в файл **~/cron_test/cur_minute.txt** можно добавить в **crontab** строку:
```cronexp
* * * * * /bin/bash ~/each_minute_script.sh >> ~/cron_test/cur_minute.txt
```
По итогу в файле **~/cron_test/cur_minute.txt** каждую минуту будет появляться строка с указанием текущей минуты (от 0 до 59). 

Очень частым примером использование крон задач является периодическое создание бэкапов.
Например, можно каждую полуночь создавать бэкап и писать логи этого процесса в специальный файл:
```cronexp
0 0 * * * /bin/bash ~/midnight_backup.sh >> /var/log/backups/midnight_backups.log
```
Логи сервисов и всяких периодических процессов принято хранить в директории **/var/log**.
