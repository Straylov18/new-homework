# Развертка backend на сервере как сервис

## Настройка сервера перед запуском приложения

Изначально при развертке сервера на нем будет скорее всего один пользователь **root**.
Под этим пользователем можно делать все что угодно. 
Запускать приложения под ним будет опасно.

Поэтому первым делом создадим нового пользователя под которым в дальнейшем будем заходить на сервер и запускать там свои приложения:
```shell
useradd -m -s /bin/bash --group sudo new_user_name
```
В данном случае создастся пользователь new_user_name с правами суперпользователя (за это отвечает параметр '--group sudo').
Однако в отличие от пользователя root, 
этот пользователь должен будет ввести пароль перед тем как выполнить какое-то опасное действие.
Для этого пользователя также создастся своя домашняя директория /home/new_user_name (за это отвечает параметр '-m').
Также у нового пользователя будет использоваться bash консоль по умолчанию (параметр '-s /bin/bash').

Дальше этому пользователю можно задать пароль используя команду:
```shell
passwd new_user_name
```

После этого создай файл **~new_user_name/.ssh/authorized_keys** 
и добавь в него свой публичный ключ, 
чтобы в дальнейшем попадать на сервер под этим пользователем.

## Базовая настройка веб сервера и маршрутизации через nginx

Чтобы запросы пользователей обрабатывались на сервере при помощи нужных приложений, 
необходимо настроить на сервере специальное приложение - **веб сервер**. 
В нашем случае **nginx** (является наиболее популярным на данный момент).

установим его:
```shell
sudo apt update
sudo apt install nginx
```

Он сразу заработает в системе как сервис.

**Сервис** - это программа, которая работает в фоновом режиме. 
Им можно настроить поведение, например запуск при старте системы.

Проверим, что nginx заработал:
```shell
service nginx status
```
**service** - команда, позволяющая нам производить операции с сервисами в системе linux.
Ей можно перезапускать, останавливать, поднимать сервисы, а также смотреть их статусы.

Чтобы посмотреть информацию о всех сервисах, запущенных в системе:
```shell
service --status-all
```
