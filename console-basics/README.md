## Навигация

Для начала удобно воспринимать консоль как проводник в операционной системе, 
с тем отличием, что все операции ты делаешь через специльные команды.
Т.е. консоль это просто интерфейс взаимодействия с системой через команды.
Эти команды отличаются для разных операционных систем, 
здесь мы рассмотрим команды для unix-подобных операционных систем (таких как MacOS, Linux итд.), 
поскольку с ними разработчики так или иначе сталкиваются при работе.


Например чтобы посмотреть в какой папке (также папка часто называется каталогом или директорие) ты сейчас находишь можно выполнить комманду:
```shell
pwd
```

Чтобы посмотреть, что находится в текущей папке:
```shell
ls
```

Зачастую команды имеют множество настроек, которые невозможно запомнить для всех существующих команд.
Поэтому для упрощения жизни пользователям команды хранять в себе подсказки, 
которые можно получить, запуская их с параметром **--help**.

Так, если ты хочешь узнать параметры команды ls:
```shell
ls --help
```

это выдаст тебе:
```
Usage: ls [OPTION]... [FILE]...
List information about the FILEs (the current directory by default).
Sort entries alphabetically if none of -cftuvSUX nor --sort is specified.

Mandatory arguments to long options are mandatory for short options too.
  -a, --all                  do not ignore entries starting with .
  -l                         use a long listing format
...(на самом деле там сильно больше текста)...
```

Итак мы видим, что эта команда может вызываться с дополнительными параметрами.
Зачастую легче использовать следующий формат команды ls (чтобы вывод был более читаемым и чтобы команда выводила полный список содержимого текущей папки):
```shell
ls -la
```

Советы (могут показаться банальными, но вспоминай их каждый раз, когда что-то идет не по плану):
- Запомни, в профессии разработчика ты будешь часто сталкиваться с чем-то новым, 
главное уметь быстро искать ответы на свои вопросы.
Чтение --help для команд, например, зачастую быстрый из возможных способов получения информации о ней, 
однако если тебе очень сложно, можешь прибегнуть к помощи браузера (погуглить) 
или спросить у нейросети (если спрашиваешь о чем-то повсеместно используемом).
Зачатую для поиска ответов на вопросы по разработчике программ хорошо подходят такие сайты как stackoverflow.com.

- Также тебе необходимо научится читать то, что тебе выводит программа (если тебе не понятно что написано в выводе, гугли этот текст).


Для перехода в другую папку необходимо использовать команду **cd**.
Чтобы было нагляднее, представим себе следующую структуру папок в операционной системе:
```
opt --- dir1 --- foo.txt
     |
     -- dir2 --- bar.txt
              |
              -- cat.jpg
```
Чтобы перейти из любого места в системе в конкретную папку мы можем задать полный путь начиная с символа **/**:
```shell
cd /opt/dir1
```
Теперь мы в dir1, можем проверить это с помощью pwd, он выдаст нам "/opt/dir1".

Перейдем в папку выше (конструкция '..' означает переход на папку выше, относительно текущего адреса):
```shell
cd ..
```
Теперь мы в папке "/opt".

Чтобы перейти по относительному пути (без указания полного пути от корневого каталога системы)
необходимо вбивать путь без '/' в начале.
Т.е. чтобы перейти из папки "/opt" в папку "/opt/dir2" можно просто написать:
```shell
cd dir2
```

Конструкция '..' можно комбинировать с другими именами файлов. 
Чтобы перейти из папки "/opt/dir2" в папку "/opt/dir1" можно написать сразу:
```shell
cd ../dir1
```
