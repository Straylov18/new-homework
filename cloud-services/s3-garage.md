# Локальное S3 хранилище (garage)

Для проверки работы системы локально 
без подключения к облачным хранилищам можно использовать локально разворачиваемое S3 хранилище. 
В данном примере предоставляется конфигурация локального S3 хранилища **garage**.

Существует также (до определенного момента популярный).
Minio имеет меньше возможностей по развертыванию без лишнего нажатия на кнопки в интерфейсе.
Также minio в один момент стал платным.
В связи с этими факторами его сейчас намного реже используют в разработке, 
поэтому его мы рассматривать не будем.

## Запуск

Запуск garage и web интерфейса:
```shell
make start_s3_garage
```

Хранилище будет доступно по адресу:
http://localhost:3909.

## Настройка и подключение

### Генерация логина/пароля для garage-webui

Для генерации пары логин-пароль для **garage-webui** придется установить **htpasswd**:
```shell
sudo apt install apache2-utils
```

Сгенерировать пару логин-пароль для **garage-webui** 
в интерактивном режиме можно при помощи скрипта:
```shell
make generate_user
```

### Настройка бакетов, ключей подключения

Чтобы настроить хранилище 
(создать бакет, сгенерировать ключи доступа итд.) 
можно воспользоваться скриптом:
```shell
make setup_s3_garage
```

После настройки гаража скриптом,
для подключения к S3 можно использовать следующие переменные окружения:
```
S3_BUCKET_NAME=data-bucket
S3_URL=http://localhost:3900
S3_KEY_ID=...
S3_SECRET_KEY=....
S3_REGION=garage
```

Запуск и настройка:
```shell
make start_and_setup_s3_garage
```
