# S3 хранилище

**S3 (Simple Storage Service)** - это облачное объектное хранилище данных. 
Оно было разработано компанией Amazon Web Services (AWS). 
Сегодня аналогичные решения предлагают и почти все облачные провайдеры.

В отличие от традиционных файловых систем с иерархией папок и подпапок 
или блочных хранилищ, 
S3 использует объектную модель хранения.

Каждый файл (изображение, видео, документ и т.д.) 
сохраняется как самостоятельный объект, который включает:
- основные данные - собственно содержимое файла
- метаданные - информацию о файле 
  (тип, дата создания, размер, пользовательские теги и т.д.)
- уникальный идентификатор (ключ) - адрес для доступа к объекту

Объекты группируются в бакеты (buckets) - контейнеры с:
- глобально уникальным именем (похоже на домен)
- заданным регионом размещения (например, «EU — Франкфурт»)
- индивидуальными настройками доступа и политиками хранения

### Способы взаимодействия с S3

Доступ к данным осуществляется через:

- REST API (HTTP/HTTPS‑запросы)
- SDK для разных языков программирования
- веб‑интерфейс управления хранилищем

### Ключевые особенности и преимущества

- Масштабируемость. 
  Объём хранилища не нужно резервировать заранее: 
  он растёт по мере добавления объектов - от килобайт до петабайтов.

- Надёжность и доступность. 
  Данные автоматически реплицируются (обычно 3+ копии) 
  в разных стойках внутри региона или даже в разных географических зонах. 
  Стандартная доступность — 99,99 %.

- Безопасность.
  Поддержка шифрования (в т.ч. «на лету»), 
  гибких политик доступа (ACL, IAM), аудита действий, 
  защиты от случайного удаления (Object Lock).

- Экономичность. 
  Оплата только за фактически используемый объём и количество операций 
  (модель pay‑as‑you‑go), без фиксированных платежей.

- Быстрый доступ и интеграция. 
  Возможность настройки публичного/приватного доступа, 
  генерации временных ссылок, совместимости с CDN для ускорения доставки контента.

- Версионирование. 
  Сохранение предыдущих версий объектов позволяет восстановить данные после ошибок.

### Частые сценарии применения

S3 часто используют для хранения:

- статического контента сайтов (html, css, js, картинки)
- медиафайлы
- бэкапов
- артефактов
- документы (например, чтобы не генерировать их снова на бэкенде)
- любые файлы пользователей кокой-либо системы
